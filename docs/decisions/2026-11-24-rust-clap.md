# 兩支 Rust CLI 以 clap 宣告及解析命令列

## 狀態

`accepted`。2026-11-24 使用者在檢閱參數順序、子命令 help 及未知旗標的實測結果後確認遷移。

## 背景

原先兩支 Rust CLI 各自比對參數，另外維護 help。調換 `activities list` 的選項會讓查詢失敗，檢查器也曾將未知旗標視為檔名。

## 決策

合併器與 Rust 檢查器採用 clap derive 定義命令、選項及參數關係，由該定義產生 help 和語法診斷。各自保留內嵌的 agent 指引、版本診斷及執行結果契約。[合併器規格](../spec/merger.md) · [檢查器規格](../spec/inspector.md)

## 影響

命令列先驗證語法，再載入設定或開啟 FIT。全域選項可在各層子命令使用。使用者可在輸入檔名後要求該命令的 help。合併器在解析失敗時也能依 `--json` 回傳結構化診斷。

## 替代方案

逐一補上手寫分支需要在各命令重複實作選項順序、未知旗標與 help。既有群組入口的行為差異已在實測中重現。

## 後續工作

新增命令時，更新其 clap 宣告與相應的 agent 主題，並以實際執行檔驗收選項換序、失敗時的 stdout、stderr 和結束碼。
