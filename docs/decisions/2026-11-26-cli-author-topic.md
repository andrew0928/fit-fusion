# 每支 CLI 從 skill 索引提供共用作者頁與專案網址

## 狀態

`accepted`。2026-11-26 使用者指定所有發佈的 CLI 提供 `--skill author`，並要求把專案網址和這項介面規範納入共用範本。

## 背景

使用者可能只安裝其中一支工具。只要取得執行檔，就應能找到維護者的公開聯絡方式及對應的原始碼。

## 決策

每支工具都在 `--skill index` 列出 `--skill author`。同一專案共用一份離線作者頁，列出作者姓名、Facebook 粉絲專頁、部落格、作者介紹、專案網址及工具介紹文章。文章發表前標示「待刊登」。[作者頁](../../src/python/fit_fusion/guides/author.md)

## 影響

五支原生 CLI、檢查器 bridge 與各語言檢查器共用相同內容。驗收逐支核對索引及實際輸出。[共同介面規格](../spec/cli-common.md)

## 替代方案

各工具分別維護作者資訊會增加更換網址時的工作，並可能讓同一版工具顯示不同連結。

## 後續工作

工具介紹文章刊登後，更新共用作者頁並隨下一版執行檔發佈。
