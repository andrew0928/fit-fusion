# 0.2.x Homebrew 供測試，0.3.0 為首次正式發佈

## 狀態

`accepted`。2026-11-25 使用者確認 Homebrew 現階段供測試，預計 0.3.0 首次正式發佈，先前列出的發佈注意事項須在該版發佈前完成。同日使用者確認已完成乾淨環境驗收，M4-7 R14 通過 review。

## 背景

公開 tap 已提供 0.2.2 五支 Apple Silicon CLI。這版驗證了匿名下載、SHA-256 與首次安裝，也提供後續測試升級的起始版本。[Homebrew 決策與驗證紀錄](2026-11-25-homebrew-cli.md)

## 決策

0.2.x 保留為 Homebrew 分發測試階段。使用者已確認 0.3.0 交付版控來源、公開內容的隱私與授權檢查、Homebrew 升級驗收、共通設定及舊 CLI 退場指引。候選附件保留匿名下載與 SHA-256 校驗。M5-2 自動建置已取消。0.3.0 採[手動發佈主 repo、自動更新 tap](2026-11-26-public-source-and-release.md)。[M5 任務](../milestones/m5-release.md)

原清單曾將 Developer ID 簽章與 Apple 公證列為必要條件。2026-11-25 使用者說明目前沒有 Apple Developer 帳號，明確指定本版略過此項，取代原條件。

## 影響

2026-11-25 使用者指定 M5 以發佈 0.3.0 為目標，將原先列在 M4-7 的五項發佈前工作依序移為 M5-1 至 M5-5。M4-7 以 0.2.2 的 R14 首次安裝驗收結案。當時規劃由公開 tap 提供私有開發庫的版本附件，2026-11-26 改採[在開源主 repo 發佈 binary](2026-11-26-public-source-and-release.md)。

## 替代方案

直接將現有 0.2.2 視為首次正式發佈，會略過從已安裝版本升級的實測及新舊 CLI 的移轉指引。

## 後續工作

依清單從已提交的來源產生候選版。正式發佈前留下可核對的建置、附件校驗及升級紀錄。[R14 review](../spec/testcases/m4-cli.md#r14review)
