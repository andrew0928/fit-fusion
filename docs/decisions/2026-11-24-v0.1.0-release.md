# 以 GitHub Release 發佈 v0.1.0

## 狀態

下列狀態記錄 v0.1.0 發佈當時的範圍。2026-11-25 起，M3 需求由 M4 承接，M2-4 已廢除。[後續規劃](../milestones/m4-cli.md)

`accepted`。2026-11-24 騎士確認 M16、M17 略過，以 M15、M18 代表舊設備驗收，M3 全部 pending，先建立 `v0.1.0` tag 並透過 GitHub Release 發佈。

## 背景

M2 可按日期配對、合併並產生可手動上傳 Strava 的 FIT。現有舊設備樣本已完成 Rider 15 Neo 單機保留及排除不同趟的實測。騎士手上已無其他原始 FIT。

## 決策

本版以 M15 與 M18 作為舊設備代表案例，M16、M17 的實機案例標記略過。以同一個 Git tag 發佈原始碼與 macOS Apple Silicon 的 `fit-fusion`、`fit-inspector` 執行檔，提供 SHA-256 供下載後核對。

## 影響

M2-4 維持 pending，發佈到 Strava 採網頁手動上傳。M3 的憑證保管、正式套件發佈流程及其他整合全數 pending。v0.1.0 的 GitHub Release 是本次版本交付。

## 替代方案

曾規劃等待更多舊 FIT 完成 M16、M17。現有合成功率補值測試保留為跨來源選值的對照案例。

## 後續工作

後續版本再排定 M3 的設計與 PoC。[里程碑](../milestones/m2-cli.md) · [實檔驗收](../spec/testcases/merger.md#舊車錶與跨廠牌實檔驗收m15m18)
