# Milestone 1-1 使用獨立 C# CLI 驗證同一份 FIT

## 狀態

accepted。2026-11-21 使用者確認追加 milestone 1-1，要求用對等的 C# 檢測 CLI 當作兩份 FIT 的對照組。此項決議確認檢測工作的範圍；正式版函式庫另見[選型提案](2026-11-21-production-fit-sdk.md)。

## 背景

既有 Python 檢測可以逐筆匯出、驗證 CRC 並統計感測欄位。另一個解碼器直接讀同一份原檔，可檢出位元組序、區域訊息定義、未知欄位與無效值處理的差異。

## 決策

兩邊各自執行 `raw` 與 `inspect`。以解析後的 JSON 比對每個 frame 的位置、原始位元組、定義、欄位順序、數值及完整統計，並核對可還原的來源 SHA-256。每個 FIT 單獨驗收。

## 影響

本輪 C# 實作使用 .NET 10 內建 API；執行環境無法連到 NuGet。Python 可選離線解碼器。兩者共用公開 profile 名稱與單位對照，分別實作解碼及時間與覆蓋率統計。此次實檔驗證適用於這兩個實作。

## 替代方案

Garmin 官方 C# SDK 適合後續讀寫相容性評估；本輪採可離線建置的實作，以便重現每一個原始 frame。只比較活動總距離與平均心率會漏掉私有欄位、定義及取樣差異。

## 後續工作

保留兩份樣本及驗證命令，供後續 SDK 選型重跑。若新增具名解碼器或另一版 profile，分開記錄欄位命名差異與實際數值差異。
