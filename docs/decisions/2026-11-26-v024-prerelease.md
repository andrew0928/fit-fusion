# 0.2.4 預發佈移除舊 fit-fusion 的原始碼與執行檔

## 狀態

`accepted`。2026-11-26 使用者指定以 0.2.4 pre-release 提前移除舊 CLI，包含原始碼，並重跑驗證。此決策取代[原定於 0.3.0 才移除](2026-11-26-v023-upgrade-and-retirement.md)的時程。

## 背景

五支獨立工具已在 0.2.3 通過公開 Homebrew 升級驗收。該版的通用壓縮檔額外提供舊合併器，其 crate 目錄也存放現行工具共用的合成 FIT。

## 決策

刪除舊 Rust crate、指引及只執行舊 CLI 的測試。將合成 FIT 移到共用測試目錄。預發佈使用 Git tag `v0.2.4`，GitHub 標記為 pre-release。五支 CLI 的版本號為 0.2.4，通用套件另含跨語言檢查器所用的 bridge。

## 影響

舊版自動日期配對、逐點備援及 Parquet 輸出可從 v0.2.3 歷史標籤重現。現行合併採明確指定兩個 FIT 與待覆寫串流的介面。Homebrew 套件名、三支 query 的 YAML 路徑與公開穩定版維持 0.2.3 的安裝契約。

## 替代方案

先前規劃在 0.3.0 首次交付移除變更。此次透過預發佈，在正式版前驗證 Git 原始碼、套件內容與實際資料流程。

## 後續工作

驗證匿名下載、五支 CLI、bridge、來源查詢與 FIT 合併讀回，核對公開 tap 的穩定 Formula。[M5 驗收紀錄](../milestones/m5-release.md)
