# 在 0.2.x 完成驗收，0.3.0 移除舊 CLI

## 狀態

`superseded`。退場時程由[0.2.4 預發佈決策](2026-11-26-v024-prerelease.md)取代。原確認記錄如下。

2026-11-26 使用者指定準備 0.2.3 並進行升級測試，0.2.x 持續推進到驗收完成，0.3.0 唯一的產品變更為移除舊 `fit-fusion`。

## 背景

0.2.2 已通過首次安裝驗收，Homebrew 提供五支工具。主 repo 的通用壓縮檔另含舊合併器與檢查器 bridge。新 YAML 與參數來源顯示原排在 0.3.0。[原發佈計畫](2026-11-25-first-stable-release.md) · [設定介面](2026-11-26-config-init-and-effective-arguments.md)

## 決策

0.2.3 的五支獨立 CLI 一起升至 0.2.3，提供個人 YAML、初始化與執行前摘要。通用壓縮檔繼續提供 `fit-fusion 0.1.0` 及 `fit-inspector-bridge`，Homebrew 沿用五支 CLI 的安裝範圍。從正式 0.2.2 的同名套件實際執行升級，保存個人設定及升級後的功能證據。

## 影響

M5-4、M5-5、發佈事件與 Formula 的匿名下載驗證、授權選定及第三方再分發檢查均排在 0.2.x。依結果追加 patch 版。舊 `fit-fusion` 的 JSON 契約在 0.2.x 仍可使用。0.3.0 移除舊 CLI，保留五支獨立工具、套件名稱及 YAML 設定。

## 替代方案

原規劃在 0.3.0 同時交付新設定與舊工具退場。分兩階段後，使用者可在仍有舊工具的版本驗收新流程。

## 後續工作

在 [M5 驗收表](../milestones/m5-release.md) 分別記錄本機候選套件升級、公開 Release 觸發同步、使用者 review 與 0.3.0 的移除驗證。
